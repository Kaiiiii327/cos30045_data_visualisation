# COS30045 Data Visualisation

## Project Overview
This project explores television energy consumption data published by the Australian Government.

## Data Story

### Audience
Australian consumers who are planning to buy a TV and want simple information about TV choices and energy use.

### What the Audience Wants to Know
The story focuses on:
- available screen technologies
- common screen sizes
- brands with the most models
- screen technology and power consumption
- screen size and power use
- screen size and star rating

### Story Goal
The goal is to help consumers understand common TV choices and how television characteristics relate to energy use.

## About the Data

### Data Source
The television energy-rating dataset was obtained from the Australian Government data portal, data.gov.au.

### Data Processing
The dataset was processed using KNIME.

The workflow included:
- reading the CSV file
- checking and removing duplicate records
- checking missing values
- filtering relevant television models
- removing unnecessary columns
- standardising brand names
- converting screen size from centimetres to inches
- grouping and aggregating data for visualisation

### Privacy
The dataset contains product information about televisions and does not contain personal information about individual consumers.

### Accuracy and Limitations
The analysis is based on the records available in the dataset.

The dataset may not represent every television currently available in the Australian market, and the results depend on the accuracy of the original submitted product information.

### Ethics
The visualisations are presented using the processed dataset without intentionally changing or exaggerating the results.

Charts and descriptions are used to communicate the findings clearly to consumers.
