About the Project

About This Website

This website was developed as part of COS30045 Data Visualisation at Swinburne University of Technology.

Project Purpose

The purpose of this website is to demonstrate the use of HTML, CSS and JavaScript while presenting information about household appliance energy consumption.

Television data was processed and explored using KNIME before selected visualisations were included on the website.

Data Source

The project uses television energy rating data published through the Australian Government data portal.

The dataset contains information such as television brand, model number, screen technology, screen size, star rating and average-mode power consumption.

Data Processing

KNIME was used to inspect, clean and transform the television dataset.

The workflow included filtering data, checking duplicate models, standardising brand names, converting screen sizes from centimetres to inches and creating visualisations.

GenAI Acknowledgement

Generative AI was used as a learning assistant during website development. It was used to explain HTML, CSS and JavaScript, suggest code structure and assist with debugging.

The generated code was reviewed and adapted for this activity.
